# HomeTTY widget companion

Adapted from https://github.com/termux/termux-widget.git at `b3aacb8175fb2d7167ce8d1ad6817087498aa044`.

Upstream source namespaces and notices retained. Application ID, permissions,
shared UID and prefix target HomeTTY. Uses this repository’s adapted termux-shared.
Debug signing uses the same local SDK key as the main app. Device verification
is required; upstream README describes upstream distribution, not HomeTTY.
